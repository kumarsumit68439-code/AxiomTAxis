Counting

/counting set #channel · /counting reset · /counting status

Sequential numbers in channel. Wrong / same user twice → reset. Milestone every 100.

Level / XP

/level set · /level rank · /level leaderboard

XP 15–25 per message (1 min cooldown). Level-up in configured channel.

Ticket

/ticket setup channel:#support category:… support_role:@Staff

Panel opens private ticket; Close deletes after 5s.

Verification

/verification setup channel:#verify role:@Verified

Verify button grants role. Bot role must be above verified role.
